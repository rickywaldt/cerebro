## Portworx

A storage provider/provisioner. Software Defined Storage (SDS).

## STORK

The Storage Orchestrator Runtime for Kubernetes acts as a [[Kubernetes Scheduler]] extender. It communicates with [[Portworx]] and it provides information to the scheduler on which nodes the storage lives. The scheduler will add this information (storage locality score) to the total scores for scheduling pods to nodes.

## Kubernetes Scheduler

Looks at CPU, memory, taints, affinity etc. to make decisions on which nodes to schedule pods. It does this by coming up with a total score based on the aforementioned parameters. Nodes with a higher score are better candidates for scheduling.
